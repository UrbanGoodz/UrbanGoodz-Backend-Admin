## Interpretation limits

- A detected control proves source presence only.
- Blade expressions, JavaScript-generated controls, component indirection, and runtime feature flags can produce duplicates or omissions.
- A route expression is not proof that the named route exists, its middleware is correct, its controller succeeds, or its state persists.
- Hidden permission branches are counted even when a current user cannot see them.
- Mobile widget presence is not proof that its repository uses real backend data.
- No “wired,” “tested,” “staging,” or “live” conclusion is derived from the census alone.
