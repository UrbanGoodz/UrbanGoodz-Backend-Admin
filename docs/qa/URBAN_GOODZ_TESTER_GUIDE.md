# Urban Goodz Tester Release Guide and Instructions

## 1. Overview
Welcome to the Urban Goodz Platform Staging Release! This guide provides testing instructions for Customer (Shopper), Driver, Vendor mobile applications, and Web Portals (Admin, Business, Dispatcher).

## 2. Installation and APK Setup
Download the release APKs from the outputs folder:
- **Shopper App**: `UrbanGoodz_Shopper_Tester_Final.apk` (`com.urbangoodz.customer`)
- **Driver App**: `UrbanGoodz_Driver_Tester_Final.apk` (`com.urbangoodz.driver`)
- **Vendor App**: `UrbanGoodz_Vendor_Tester_Final.apk` (`com.urbangoodz.vendor`)
